# SeccionEtapa.tsx

## Summary
Encabezado de página de etapa (h1; letra en el color de la etapa) y bloque de paso (h2) con el fondo de la etapa, borde fino, sombra difusa y, si la etapa lo pide, manchas de luz como las del fondo de página. Dentro de la tarjeta el texto secundario usa el color principal por contraste.

## Functions
- SeccionEtapa({etapa, descripcion})
- BloquePaso({paso, ancho, tarjeta})

## Non-function code
Estilos en SeccionEtapa.module.css (data-manchas, --fondo-paso, --borde-panel, --sombra-panel).
