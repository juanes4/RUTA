# etapas.ts

## Summary
Etapas 0, R y U activas; T y A vacías. Cada etapa activa tiene color de nodo (0 crema, R azul, U lavanda) y estilo de tarjetas de sus pasos (0 crema con manchas de luz, R alterna azul y gris, U lavanda).

## Functions
- anclaPaso(idPaso) — id HTML del paso
- tarjetaDePaso(etapa, indice) — fondo y manchas de la tarjeta de un paso

## Non-function code
ETAPAS; tipos Etapa, PasoEtapa, TarjetasEtapa, EstiloTarjeta.
